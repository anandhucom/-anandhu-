# Anandhu P S — Personal Portfolio 🚀

> **Data Scientist | AI & Machine Learning Enthusiast | Junior AI Engineer**

A sleek, responsive, tech-focused personal portfolio website showcasing end-to-end Machine Learning pipelines, NLP systems, and predictive modeling projects.

Live Site: [https://anandhu114.github.io](https://anandhu114.github.io)

---

## 🌟 Portfolio Highlights

- **Hero Section**: Interactive neural network canvas, dynamic role typewriter effect, quick resume download, and contact navigation.
- **About Me**: Professional summary, background highlights (B.E. in Computer Science & Engineering), and core architectural focus pillars.
- **Skills Grid**: Interactive categorized badges for Python, C, C++, R, SQL, Data Science, AI/ML, Deep Learning, NLP, Scikit-learn, TensorFlow, Keras, and Pandas.
- **Featured Projects**:
  1. **Text Sentiment Analysis using NLP**: Logistic Regression tweet classifier with TF-IDF n-grams.
  2. **Bengaluru House Price Prediction**: Real estate regression models with GridSearchCV hyperparameter optimization.
  3. **Customer Segmentation**: Unsupervised K-Means clustering leveraging the Elbow Method.
  4. **Context-Aware QA System**: Factual LLM question-answering pipeline with semantic retrieval.
- **Interactive UI**:
  - 3D card hover tilt effects.
  - Project detail deep-dive modal windows.
  - One-click copy email button with toast feedback.
  - Validated contact form.
  - Back-to-top button with circular SVG scroll progress indicator.

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, CSS3 Custom Properties (CSS Variables, Flexbox, Grid, Glassmorphism), Vanilla JavaScript (ES6+).
- **Visuals**: HTML5 Canvas (Neural Network / Constellation Graph), Inline SVG Icons.
- **Typography**: Inter & JetBrains Mono.
